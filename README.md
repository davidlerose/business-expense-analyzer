# Business Expense Analyzer

A command-line expense tracking application built with Python.

## Features

- Add expenses with a name, category, and amount
- Validate user input
- Save and load expenses using JSON
- View recorded expenses
- Generate reports showing total expenses and spending by category
- Handle common file-reading and file-writing errors

## Technologies

- Python
- JSON
- File handling
- Exception handling

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project directory.
4. Run:

   `python expense_analyzer.py`
